# 司天的科学定位与可证伪 claim（2026-09-04 定稿草案）

> **历史草案，已被后续协议替代。** 当前定位和比较口径以
> [预报员协议](FORECASTER_AGENT_PROTOCOL_2026-09-07.md) 和
> [首轮 RL 技能试验](RL_SKILL_PILOT_2026-09-09.md) 为准。
> 下文“回归器做不到”“回归器几乎必胜”、GRPO 等同会商、oracle-switch 为能力上限，
> 都不是已证实结论。置信区间包含零不代表等效或非劣；旧冻结探测结果也不是本轮
> 同原生路径的 frozen 对照。C1 的主要归因对照改为同模型、同工具预算的 RL 前后比较。

## 0. 一句话定位

司天不是"用 LLM 做空气质量预报模型"，而是**把预报员这一层做成可学习、可追溯、可评价的决策过程**：
数值模式（CAMS/GFS/IFS）负责算，agent 负责像预报员一样在多源证据下做决策；预报员的知识进
harness（证据组织、工具、约束）和 reward（分量化考核），强化学习让通用模型学会这套决策。

业务分工本来就是：数值模式 → 指导产品 → 统计订正（MOS）→ 预报员 → 发布。agent 对应的是
**预报员那一层**，不是数值模式，也不是 MOS。这决定了比较对象、指标和成功标准。

## 1. Agent RL 在这件事里到底适合干什么

适合（结构性优势，且可测）：

| 优势 | 为什么回归器做不到 | 怎么测 |
|---|---|---|
| 决策而非点估计 | 输出是等级、首要污染物、过程起止峰值、区间和**引用的证据**，与发布口径同构 | 事件层列联指标、过程时序误差 |
| 追溯与忠实 | 结论能回到具体证据字段，并且删掉证据结论会变 | grounding 完整率 + 反事实证据遮蔽 |
| 稀有配置的泛化 | 6,000 case 里事件只有几百个；拟合回归到均值，先验+推理能迁移物理机制 | 事件分层、空间 OOD、前瞻冬季 |
| 证据可扩展 | 加一个工具不需要重训特征 | 加证据/减证据的剂量反应 |
| 相对考核即会商 | GRPO 组内相对优势 = 会商考核的形式化 | 自我会商离散度 vs 技巧 |

不适合（不要去 claim）：

- 稳定天气下的平均 MAE，回归器几乎必胜，这是 MOS 六十年的老结论；
- 区间的精细校准，分位回归天然更好；
- 单次预报成本，12 轮工具调用 vs 微秒。

气象学文献里人类预报员对 MOS 的增值恰好也是这个形态：平均上越来越小，高影响事件和
转折上仍然存在。agent 作为"学出来的预报员"，预期增值形态一致。这不是借口，是**先验预测**，
训练前写下，训后对照。

## 2. 三层 claim 与证伪条件

按"确定性 × 新颖性"排序，任何一层失败都有下一层兜底，但每层都要事先写清楚怎么算失败。

### C1 能力 claim（主结果）

通用 LLM 在预报员知识构造的可验证 reward 下经 RL，能做出证据落地的预报决策，
整体不劣于业务数值指导（CAMS），且在事件层优于它。

- 证据：独立 val 对 CAMS 的分块 CI 下界 > 0；≥100 个隐藏真值 AQI≥4 事件 case 上同样成立；
  winter challenge 不退化。
- 证伪：训后事件层对 CAMS 的 CI 含 0，则 C1 降级为"达到指导水平"，主结果换成 C2。
- 当前起点：冻结 8B 对 CAMS −0.10 [−0.18, −0.03]，胜率 32%。

### C2 过程 claim（区分性贡献）

学到的决策过程是**忠实**的：预报因果依赖于被引证据，reward 分量分解能说明模型学到了
哪一部分预报员知识。

- 证据：① grounding 完整率；② 反事实遮蔽，删被引证据 → 预报改变率显著高于删未引证据；
  ③ 充分性，仅给被引证据 → 预报保持率；④ 分量学习曲线（level/event/interval/turning/primary）
  与 strategy_attribution 迁移（从 persistence/guidance 归因迁移到综合）。
- 证伪：删被引与删未引证据的改变率无差异，则"可追溯"只是事后合理化，论文只能报引用率。
- 这一层与准确率独立，训练成功与否都能出结果。

### C3 增值形态 claim（高回报、不保证）

相对同信息集统计订正（tabular = MOS），agent 的增值集中在事件、转折和分布外，
而不在平均分。

- 证据：事件层 composite、硬 CSI、峰值时序 MAE 三项分块 CI 下界为正；整城空间 OOD test
  上超过 tabular；遮蔽 synoptic+composition 出现正的剂量反应。
- 证伪：事件层也不及 tabular，则如实报告"同信息集下推理未产生超过拟合的增值"，
  C1/C2 仍然成立。tabular 在这里是**对照**，回答"证据里有多少信号、增益来自证据还是推理"，
  不是标题里的对手。
- 当前起点：冻结 8B 对 tabular −0.15；tabular 事件分量本身只有 0.15，谁都没做好。

### C0 基准 claim（载体，稳拿）

首个防泄漏、可验证、前瞻评测的多源证据预报决策环境：120 城 × 7,548 case、开放证据 v2、
预报员知识 reward、干净窗口、冬季前瞻。这一层不依赖训练结果，是 C1–C3 的容器。

## 3. 比较阶梯（论文表格的行顺序）

```
persistence / climatology      下限，防假学
CAMS 指导                      业务参照，C1 的对手
tabular（同信息集 MOS）         统计订正对照，C3 的对手，明写"不主张平均超过它"
冻结 8B（同 policy 未 RL）      RL 归因，C2 的对手
RL agent                       主角
人类预报员业务发布              最有说服力的同层参照，尚缺（见 §6）
oracle-switch                  简单策略切换上限，超它 = 证明合成订正
```

## 4. 四维评测，每维要有可陈述指标而不只是 reward 分量

| 维度 | 指标 | 现状 |
|---|---|---|
| 准确 | composite、六项 IAQI MAE、等级命中 | 有 |
| 关键事件决策 | AQI≥4 的 POD/FAR/CSI、转折日误差、首要污染物切换命中、峰值时序 MAE | reward 分量有，**独立列联指标脚本缺** |
| 可追溯 | grounding 完整率、反事实遮蔽改变率、充分性保持率 | 引用率有，**反事实实验缺** |
| 可信 | 80% 区间覆盖率与宽度、interval score、自我会商 spread-skill、OOD 退化曲线 | 覆盖率/ensemble 有，OOD 面板部分 |

以及 reward 本身的效度：reward 是"预报员知识"的形式化，这句话要由专家问卷验证
（专家在同一 harness 上填报，其决策的 reward 排序与专家自评一致），否则"可评价"是自我声明。

## 5. 定位对训练的影响

不变：reward 七分量、thinking-on、grounding 强制、阶段 A 单轮 → 阶段 B 多轮、DAPO 过滤。
这些本来就是四维的形式化。

要改：

1. 毕业门槛以 C1 为主（≥ CAMS 且事件层 ≥ CAMS 且 grounding 完整率不降），
   不再以"超过 tabular"为必要条件；tabular 结果如实报告。
2. checkpoint 选择报告加事件层 CSI 与 grounding 完整率两列，防止只按 composite 挑出
   "平均分高、事件层塌"的 checkpoint。
3. 训练前不阻塞，成文前必须：事件列联指标脚本、反事实遮蔽实验、OOD 面板。

## 6. 最大的缺口：人类预报员业务发布（2026-09-04 调研结论）

按这个定位，真正的同层参照是人类预报员的业务发布。调研结果：

| 来源 | 粒度 | 回溯性 | 结论 |
|---|---|---|---|
| 全国空气质量预报信息发布系统 air.cnemc.cn:18014 | 46 城（与 120 城重叠 35）、逐日、未来 7 天 AQI 区间/等级/首污 | **只有当日**，无历史接口，Wayback 零快照 | 干净窗口内不可回溯；从 2026-09-04 起每日采集，供 2026–27 冬季前瞻评测 |
| 生态环境部半月会商结果 mee.gov.cn | 七大区域 + 北京逐日段落，等级/首污/形势文字 | 完整归档到 2021-06，已抓 120 期 | 覆盖整个窗口的人类会商参照，但是半月展望、区域级，只能做事件层过程参照 |
| 北京市监测中心 16 时预报（微博→新浪转载） | 北京逐日、未来 3–5 天等级/AQI 区间/首污 | 微博 API 无登录被拒，新浪转载零散、完整性未知 | 京津冀基准可部分回补，需人工/登录爬取 |
| 省级发布系统（约 27 省） | 省内城市、未来 3–7 天 | 未发现历史查询 | 与 CNEMC 同样只能前瞻采集 |

采集脚本 `scripts/fetch_official_forecasts.py`（cnemc 逐日城市预报 / mee 半月会商回溯 /
nmc 中央气象台空气污染气象条件预报图与大气环境气象公报），产出 `data/raw/official_forecasts/`，
scorer-only，永不进入 agent prompt。本机 crontab 已挂每日 BJT 10:00 与 18:00 两次
（`0 3,19 * * *` 太平洋时间），日志 `data/raw/official_forecasts/cron.log`；本机会重启，上云后
同一条 crontab 再挂一份，目录以文件名去重合并即可。不再逐省搜索；全国逐日城市级历史只有
中国环境监测总站内部有，走机构申请。

因此论文里"与人类预报员比较"只能在**前瞻冬季**做（35 城 × 冬季），回溯期用半月会商做
事件层过程参照。这与毕业门槛要求 2026–27 冬季前瞻证据是同一件事。

## 7. 退路

- C1 成、C3 不成：学出来的预报员达到业务指导并可追溯，增值未超 MOS。可发，叙事偏方法与基准。
- C1 不成、C2 成：忠实决策过程但精度不足，报告为负结果 + 基准，价值在环境与评测协议。
- 都不成：只剩 C0，需要重审 reward 效度和证据充分性，而不是加大算力。
