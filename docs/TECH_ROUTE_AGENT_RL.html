从“学习答案”
到“学习预报决策”

参照 JJJ_ATMO 的问答微调与单次生成路线，当前方案把模型放进可交互、可评分、可回放的预报环境， 让策略学习如何取证、综合、订正并提交最终预报。

Agent RL 为能力训练主线 规则化结果奖励，不用 LLM Judge 当前处于数据合同与开训门禁收尾

训练对象发生了根本变化

不是换一个训练算法，而是把“样本”改造成“决策过程”

JJJ_ATMO 参考路线 回答级训练
预先整理输入与专家目标
一次性拼入 prompt
生成单个结构化回答
SFT 模仿；可选答案级 GRPO

模型主要学习：给定材料后，应该输出什么答案。

当前 Agent RL 路线 Episode 级训练
进入起报时刻受控任务环境

多轮综合、比较与订正
提交结构化预报，按观测结果给 reward

模型主要学习：为了得到更好的预报结果，应该查什么、怎么判断、最后如何决策。
