# 司天：预报员 Agent 的定位、训练目标与对照实验建议

这是 2026-09-07 代码与数据审计后的研究方案建议。它明确建议采用的实验口径，不表示这些实验已经完成，也不改动现有 reward、数据切分或训练参数。实测建设状态见 `docs/reports/rl_readiness_20260907/report.html` 和同目录 `evidence.json`。

## 1. 研究对象：从证据到预报的决策策略

**司天学习的是污染预报员的决策策略：在起报时刻可获得的多源资料下，识别需要查证的问题，选择证据，判断证据适用性与冲突，形成浓度及不确定性判断，提交可核验的预报。**

数值模式、观测和统计订正可以作为这一角色的输入工具。这里的分工是业务角色的分工，不是“统计学习不能处理这种输入或输出”的数学论断。若输入全是固定数值摘要、输出全是浓度区间，那么方法在统计上也可以被看作复杂的多源订正器；要建立预报员 Agent 的独特贡献，需要实测它的取证、整合、异常处置和迁移能力。

建议主科学问题：

> 在相同基座、起报信息、工具预算和输出规则下，Agent RL 能否改善 LLM 的污染预报决策？这种改进是否依赖所使用的证据，并能迁移到未参与训练的目标城市、时段和污染主导类型？

业务价值问题另列：这种策略相对直接发布模式指导、统计订正，以及可获得的官方业务发布，分别在哪些条件下产生增值？

不将“平均 MAE 超过所有机器学习模型”设为唯一成功条件；也不以生态位不同为由取消统计订正对照。更不能预先宣布平均误差必输或高影响事件必胜。

## 2. 真正应学习的四种能力

1. **有目的地取证。** 围绕污染积累、输送、清除、光化学或模式分歧，选择能降低当前不确定性的工具和字段；知道何时证据已足够。查询数量与推理长度本身不是目标。
2. **依情形综合和订正。** 在指导可靠时合理使用，在初值失配、地区/季节偏差、模式分歧或异常天气演变时，确定是否订正以及订正方向和幅度。合理的“不订正”也应是可获得高分的决策。
3. **形成有质量的预报与不确定性。** 对未来 5 天给出 PM2.5、PM10、O3 浓度区间；兼顾常规预报、漏报/空报、过程峰值、首污与区间校准。误报增加不能被召回提高掩盖，区间无限放宽不能被覆盖提高掩盖。
4. **在新情形下复用上述策略。** 在未用于策略训练的城市和时期，以及证据缺失、质量降低、冲突时保持技能。需按城市/地区、主导污染物、季节与 lead 分别检验，而非只报全国平均。

现有 schema 0.6.4 让策略直接提交三污染物区间与引用，等级/首污/过程由区间中点派生。可以继续使用这个稳定合同，但三种派生输出是同一浓度决策的不同业务评价，不是三个独立的策略动作。当前环境只证明字段引用可核验，不证明解释在因果上正确。

保留 thinking-on。解释质量以可观察的判断、引用和证据干预检验；不以更长的自由文本推理作为正确性的替代证据。

## 3. 训练目标与评价目标分开

### 3.1 训练优化什么

将一次起报视为有限预算下的序列决策：策略选择工具、收到证据、继续查证或提交。环境按隐藏观测真值对最后的预测打分。首轮保留已验证的 reward 0.8.1，避免同时改环境、奖励和优化器而无法归因。

- 主要学习信号来自 level、event、interval、turning、primary 等结果分量。
- grounding 保持低权重，用于约束引用真实与基本证据覆盖；不奖励推理字数、术语数或固定工具调用次数。
- 以固定总 token/工具预算约束成本；首轮不贸然增加“少调用工具得分”，避免过早学会跳过取证。
- 工具输出不进语言策略 loss；rollout 来自与训练权重同步的同一策略。
- DAPO 按结果分量是否有有效组内差异筛组，防止只有格式或引用奖励变化。仍报告筛掉了哪些污染类型，防止困难案例被系统性排除。

区间的有界指数奖励是优化代理，不是严格 proper scoring rule。80% 区间是否校准，必须用真实覆盖、宽度和原始 interval score 验证。当前事件塑形分也不代替硬 CSI/POD/FAR。

### 3.2 如何安排课程

**阶段 A：给定证据，先学习判断。** 使用预先固定、可核验的证据包，允许 thinking，提交同一预报合同；环境提供数据及基本计算，不提供建议答案、订正幅度或真值。降低工具探索和数值决策同时学习的难度。该方向已在项目责任切分文档中提出，但当前启动脚本仍是多轮工具路径，需要具体实现并验收。

**阶段 B：在同一决策能力上学习自主取证。** 允许选择工具、顺序与停止时机，继续以最终观测结果评价。真实工具输出、终止、重试、截断及 token 预算在训练与评测两端必须一致。

**阶段 C：检验泛化与稳健性。** 不改变冻结 test 来追分；在独立时段、整城 OOD 和前瞻冬季检验。缺测/冲突训练增强只作用于 train；自然缺测与人为干预结果分别报告。

若目标 BF16 基座在统一原生路径上已经会稳定使用工具，可直接开展小规模 B 阶段试验；A 是降低信用分配难度的工程选择，不是未经试验就必须经历的训练教条。SFT 只在格式或工具行为成为主要障碍时增加；如采用 SFT，必须保存 SFT-only 对照，不能把 SFT 带来的增益计给 RL。

### 3.3 三个验收层次

- **工程可训：** 目标 GPU 上实际更新、有限 loss/梯度、参数同步、工具 mask、保存恢复通过。这不要求 frozen 或小模型先胜过 CAMS。
- **学习有效：** 同基座 frozen/SFT → RL 在独立验证上出现结果技能改善，事件和校准没有被平均奖励掩盖；工具/证据行为出现可解释的变化。这是继续扩大训练预算的依据。
- **科学 claim 成立：** 固定终评上统计支持相应能力、机制或泛化主张。不同 claim 分别验收，不用一个 reward 总分代替全部结论。

## 4. Baseline 必须对应要回答的问题

| 对照 | 固定什么、改变什么 | 回答的问题 | 优先级 |
|---|---|---|---|
| 同基座 frozen Agent | BF16 checkpoint、thinking、工具、预算、解码、终止规则相同；仅无参数训练 | RL 路线相对通用模型是否改善预报？ | 主实验必须 |
| SFT-only Agent | 使用 RL 起点的同一 SFT checkpoint；工具与预算一致 | 额外收益是否来自 RL，而非冷启动监督？ | 用过 SFT 就必须 |
| 固定证据、一次提交的 LLM | 同基座与预先固定的证据视图，保留 thinking，输出相同 | 一次性综合是否已足够？ | 初轮做 frozen 对照；agency claim 需匹配训练对照 |
| 固定流程的多轮 Agent | 工具顺序与内容预注册；训练量和预算与自主策略匹配 | 多轮调用收益来自固定流程，还是自主选择？ | agency claim 必须 |
| persistence / climatology | 相同目标日、污染物与评分规则 | 是否只学会持续性或气候态？ | 低成本基本对照 |
| CAMS 等单一指导及简单偏差订正 | 对齐循环实际可用时间、lead、缺测投影；偏差只由 train 学习 | 是否超过直接发布指导或简单订正？ | 业务参照必须 |
| 强 tabular / MOS | 相同合法信息集、同训练切分；选型与校准限于 train | 增益能否由常规统计拟合解释？ | 重要增值对照 |
| 官方预报发布 / 人类预报员 | 同城市、起报截止、目标日、lead 和共同输出字段 | 达到什么业务发布水平？ | 前瞻评估；不是开训门槛 |
| 强商业 LLM（同 harness） | 同可见证据、任务与预算，锁定模型版本 | 现有证据/流程下，大模型大致能做到什么？ | 可选经验参照，不称理论上界 |

原始 NWP 气象场是输入，不适合作为空气质量结果的直接对手；CAMS 等浓度指导才是相应数值参照。官方业务发布包含其他模式、规则、资料与专家工作，不能直接等同于“纯人脑能力”。官方产品没有的浓度区间不做推造，只比共同字段。

oracle-switch 是事后取几种完整简单预报中最好的一份，只用于诊断。它不是可部署基线，也不是任意融合策略的数学上限。best-of-k 使用真值挑选时同样只能作为 oracle 诊断。

### 4.1 能单独识别 RL 与 agency 的最小实验结构

| 策略训练 | 固定证据、一次提交 | 自主多轮取证 |
|---|---|---|
| frozen | F-static | F-agent |
| 匹配训练量的 RL | R-static | R-agent |

- R-agent − F-agent：在 Agent 系统内的 RL 增益。
- R-static − F-static：不具备自主取证时的 RL 增益。
- R-agent − R-static：在匹配训练与信息/预算条件下，自主取证方案的系统增益。
- 要归因于“自主选择”，再加入匹配 RL 的固定多轮流程；否则多轮重看证据、上下文组织与更多计算仍是解释。
- R-agent − F-static 同时改变训练与交互方式，只能支持端到端系统差异。

阶段 A checkpoint 可以作为很有价值的一次提交策略。但是阶段 B 多训了多少步，一次提交对照也应从同一 A checkpoint 继续训练相同规模，不能把额外训练混入 agency 效果。

“同信息集”有两个实验口径：完整固定证据包检验整合方式，有限预算下相同可查询证据库检验取证效率。分别报告，不强行声称所有轨迹最终读到了同样的字段。固定证据包的压缩与取舍必须预注册，不能依据 agent 的成功结果或隐藏真值选择。

### 4.2 更贴近业务分工的扩展：MOS 指导加预报员 Agent

同信息集 tabular 既可以作为对照，也可以在后续独立实验中作为指导工具提供给预报员。比较“直接发布 MOS”“MOS + frozen Agent”“MOS + RL Agent”，可以直接检验预报员层在已有统计订正上的增值，而无需迫使 LLM 从头重做统计订正。

所有相应 LLM 臂必须获得同一份 MOS 指导；生成 train 中的 MOS 产品时，要使用带时间隔离的折外预测，不能使用拟合了当前案例真值的训练内预测。val/test 指导仅由相应训练资料拟合，不能回流评测真值。需另设接近实际起报约束的滚动窗口。

这不是当前首轮开训的必需补丁。现有 v1 证据合同可以先完成 RL 可学性试验；新增 MOS 工具后，应作为新的信息集版本重跑 frozen/RL/固定流程对照，不能混用旧成绩。

## 5. 报什么指标，才能称为预报员技能

**结果维度：**公平结果汇总 outcome_composite、等级命中/序数误差、三污染物浓度误差、硬事件 CSI/POD/FAR、首污集合命中与 macro-F1、过程起止/峰值误差、80% 覆盖率/宽度/原始 interval score。事件既可漏报也可空报；过程误差保留未检出的案例，不能只统计“报对过程”的子集。

**证据维度：**引用有效率、两类证据覆盖、错误引用率；同 seed 的证据遮蔽、被引/未引对照、仅被引证据充分性，以及冲突指导下的敏感性。删证据后预报改变本身不等于改得正确，应同时量化预测变化和结果质量。输入干预也不能直接证明大气机制因果链。

**泛化维度：**主导污染物 × 地区/留城市 × 季节 × lead 的分层表现与相对退化；报样本数和独立过程数。地区组表现与真正“未见地区/区制”是不同主张。当前留城设计并不是区制留出，PM10 主导标签并不是沙尘标签。

**效率维度：**最终有效提交率、每 case 工具/token 成本、重复无信息取证、延迟、相同成本下技能。保留单样本主结果；集合 k 样本另列并给所有可采样 LLM 基线相同预算。

首轮保持现有结果汇总定义，预注册主要对照为 RL 对同基座 frozen（如用过 SFT，则 RL 对 SFT-only 为直接增量对照），并并列报告 macro-stratum，防止高频暖季样本支配结论。CAMS 的业务增值与 tabular 的额外增值各列自己的效应和区间，不代替 RL 归因。

终评前冻结一个主要终点和有限的关键事件/校准约束；阈值不能根据 test 结果调节。若要证明“不劣”，预先定义业务允许的非劣界值；差值区间包含零不能证明不劣，区间下界大于零检验的则是优越性。

## 6. 当前数据能支持哪一阶段

截至本次核验：7,057 个有效 case，实际 RL train 为 3,061 case、112 城、241 个起报日，其中 383 个隐藏真值事件 case，足够支持首轮学习试验。

暖季 val 有 228 个事件，但已用于流程开发与后续选型；时间 test 只有 27 个事件，整城 OOD test 有 15 个且是时间 test 子集；冬季选择集只有 11 个起报日。它们不能支撑“全国所有地区、所有污染类型、所有季节都有效”的强断言。需继续前瞻冬季、独立污染过程和同层官方发布采集。

论文可分三层报告：

1. 同一 LLM 经 RL 学到了更好的预报决策——用同基座对照检验。
2. 决策使用了可核验且对结果有影响的证据——用输入干预检验。
3. 形成跨城市/污染类型技能及相对现有业务的增值——用分层终评和前瞻检验。

某一层成立不自动推出下一层。若 RL 有效但不及 tabular，结论是“预报员 Agent 可学习，尚未证明超过同信息集统计订正”；若只提升格式/引用而结果无改善，不能称为已学会污染预报。即便相对 frozen 有显著改善，如果仍明显逊于直接发布可用指导，也只能称为学习有效，不能称为具备业务部署价值；部署价值需另验业务非劣/增值约束。

## 7. 首轮执行建议

先收口训练/探针终止与预算合同、正式配置和保存恢复验收，再在 96 GB 目标 GPU 上进行 Qwen3-8B BF16 + LoRA 的短程试训。初轮运行主 Agent、同基座 frozen、必要的 SFT-only、已有脚本基线和 tabular；判断有学习增益后，开展匹配训练的 static/固定流程 agency 对照及证据干预。所有 thinking 设置保持一致。

无需在开训前把所有论文消融和前瞻数据准备完成；也不能在未证明参数更新和独立验证收益时，直接将大规模长训当作成功路径。
