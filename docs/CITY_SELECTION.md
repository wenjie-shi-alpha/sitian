# 城市选择方法学（全国池 v1）

**产出**：`data/interim/cities_selected.json`（120 城，完全可复现，`scripts/select_cities.py` seed=7）。

## 选择标准（按适用顺序）

1. **候选全集**：中国环境监测总站公开档案全部城市（370 个有数据城市，2021-12 → 2026-08）。
2. **数据完备性硬门槛**：评测窗口（2025-04-01 → 2026-08-26）内 PM2.5 日值覆盖率 ≥95%
   且 O3_8h 覆盖率 ≥90%（334/342 过线）。日值有效性沿用 GB 3095 口径（PM2.5 日均需 ≥20 有效小时，
   `n_hours` 字段随库携带供下游把关）。
3. **行政/人口代表性**：31 个省级行政区首府强制入选（全部通过完备性门槛，覆盖全部省份）。
4. **污染区制代表性**：其余名额按污染区制聚类分层配额。特征 = 逐月 PM2.5 气候态（12 维）
   + 逐月 O3_8h 气候态（12 维）+ log(PM10/PM2.5)（沙尘指示）+ PM2.5 事件日频率 + O3 超标日频率，
   z-score 标准化后 k-means（k=8, seed=7）。名额按簇规模比例分配，簇内取离簇心最近者
   （区制典型性优先）。气候态特征使用全档案期计算——气候态为公开背景知识，不构成对评测的泄漏。

## 为何是 120 城而非 370

RL 训练集规模受计算预算约束（见抽样设计）；120 城已实现"每省份 ≥1 城 + 八大污染区制
全覆盖 + 区制内典型性最优"。370 城的其余部分不损失区制多样性，仅增加同区制冗余。
留城市泛化评测（训练时留出部分城市）从 120 城内部划分。
