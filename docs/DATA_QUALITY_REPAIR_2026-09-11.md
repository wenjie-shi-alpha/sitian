# 数据质量修复与复验（2026-09-11）

本轮修复已确认的代码错误并生成独立数据副本。现有训练仍读取原快照；未改 reward、
策略模型、冻结清单或运行中的训练配置。修复版本不能与旧版本成绩直接混比。

## 已修复

1. 空间 OOD 聚类使用实际标签 `pm10_primary`，并拒绝未知/缺失类别，避免类别特征
   静默丢失。版本升至 `city-cluster-holdout-v2`；输出路径已存在时拒绝覆盖；在写入前
   验证训练与冬季/验证/测试的目标城市日零重叠。
2. CAMS 诊断风向从错误的 `NNE/ENE/...` 映射改为最近八方位 `N/NE/E/SE/S/SW/W/NW`。
   标签根据实际保存的数值角度计算，明确 0/360 为北、90 为东，半格边界顺时针取值。
   修复副本只修改诊断中的文字标签，原角度、其他气象量、指导和真值不变。
3. 增加可复跑的数据修复与构成检查入口：事件 case 与去重事件城市日分别计数，
   输出月份/采样类别/指导来源/逐 lead 覆盖、三项与六项 AQI 真值口径差异。
   缺失的原始抽样 case 单独列出，不用合成真值补齐。

## 本地结果

产物目录：`data/snapshots/data_quality_v2_20260911/`。

- 正式池 7,548 case，另复制并修复 1 个已有 smoke case；总共修正 30,196 条日风向标签。
- 正式训练/验证/测试清单中的风向映射不一致均归零。
- 120 城聚类中，PM10 主导特征非零的城市从 0 恢复到 105。
- 重新聚类后的留出城市与旧版相同：包头、喀什地区、安庆、潮州、聊城、舟山、遵义、鞍山。
  本次无需因城市成员变化而丢弃原划分；实际训练数仍为 3,061。
- 新训练池与冬季选择集目标城市日重叠为 0，留出城市与训练城市重叠为 0。
- 新训练池的历史指导偏差索引已独立重建：43,287 条内部记录、112 城，仅使用新训练清单。
- 原抽样清单中 752 个 case 未构建；2025-05 对应 578 个。现有构建日志只记录总计
  725 个 CAMS 缺失和 27 个观测不足，无法将每个缺失 case 精确归因。本机缺少原始
  `data/raw/cams` 和 `data/raw/aq_obs/cities`，不能在本轮重新生成缺失资料。
- 原正式清单身份已复核未变；原诊断 SHA 与修复前一致。

最终复验：8 份原清单 SHA 未变；7,549 对原始/修复诊断 SHA 与修复记录匹配；
37,747 个非诊断文件与源文件逐字节哈希一致。全量测试 **236 passed、2 skipped**；
基础静态错误检查与 `git diff --check` 通过。另有一条既有 rasterio 弃用提示。

## 产物及用途

| 路径（相对产物目录） | 用途 |
|---|---|
| `cases/` | 独立复制、已修正风向的数据包 |
| `manifests/` | 保留旧 split 成员、改指向修复副本的清单 |
| `corrected_ood/{train,val,test}.json` | PM10 特征修复后重新计算的整城留出清单 |
| `corrected_ood/audit.json` | 新聚类特征、留城成员、来源身份和隔离结果 |
| `corrected_ood/guidance_bias_history.json` | 与新 train 配套的偏差索引，不能混用旧索引 |
| `composition_audit.json` | 全量清单构成与窗口重叠检查 |
| `repair_receipt.json` | 逐诊断文件前后 SHA、逐日修复记录 |
| `unbuilt_episodes.json` | 752 个未构建 case 的补建清单 |
| `status.json` | 数据修复状态及尚未解决的实验条件 |

复跑时必须指定一个不存在的目标目录：

```bash
.venv/bin/python scripts/repair_data_snapshot.py --out data/snapshots/data_quality_v2_new
.venv/bin/python -m pytest -q
```

`status.json` 的 `training_ready=false` 是有意的：这是可审查的数据修复产物，尚未将
它切换为训练入口。启用前需冻结对应信息版本，重新生成并验证训练 Parquet/数据身份，
指定匹配的历史偏差索引；同版本重做 frozen/RL 对照。不得修改旧哈希绕过验证。

## 需要新数据或新实验的事项

O3 瞬时日最大与八小时指标不同、D5 无 CAMS 指导、冬季月份偏少、事件测试覆盖不足，
不能通过改文字或取消时间隔离来修复。当前时间 test 的27个事件case只有8个独特事件
城市日；留城test的15个事件case只有4个事件城市日，且是前者子集。三污染物预测与
六项AQI真值的可表达差异也保留在审计中。

当前训练链的 step 3 对照正确地标记为继续训练基线，没有将其伪装为原始 frozen。
要识别 RL 或自主取证增益，需要分别运行同协议 frozen 和匹配训练量的固定流程对照；
本轮未启动新模型训练，也未通过查看测试预测结果改变方案。
